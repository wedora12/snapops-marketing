# SnapOps Scene 3 --- AI Operating System Reveal

## Core Idea

Do **not** reveal a dashboard.

Reveal the **intelligence** behind the dashboard.

The audience should feel like SnapOps has just "woken up" and understood
the entire studio before presenting a workspace.

The emotion is closer to **JARVIS**, **Apple**, and **Arc Browser** than
a traditional CRM.

------------------------------------------------------------------------

# Story Flow

## Scene 2 Ends

The flatlay has fully assembled.

Everything is moving naturally.

Then...

Everything stops.

Hold for **200ms**.

Silence.

No motion.

No UI.

------------------------------------------------------------------------

# Phase 1 --- Dim the World

The desk remains visible.

Nothing disappears.

Every object slowly reduces emphasis to around **15--20% opacity**.

The viewer understands the desk is still there.

It simply becomes background.

------------------------------------------------------------------------

# Phase 2 --- System Boot

A tiny console appears in the upper-left corner.

Not centered.

Minimal.

Monospace.

    SNAPOPS OS v1.0

    ▌

The cursor blinks twice.

Type:

    > Good morning, Bharath.

Pause.

Then:

    > Connecting...

------------------------------------------------------------------------

# Phase 3 --- Studio Synchronization

Display each integration one at a time.

    ✓ WhatsApp

    ✓ Calendar

    ✓ Payments

    ✓ Albums

    ✓ Projects

Every line that appears should trigger a subtle glow on the
corresponding object in the flatlay.

-   WhatsApp → Phone glows
-   Calendar → Calendar glows
-   Payments → Contract glows
-   Albums → Album glows
-   Projects → Folder stack glows

The desk is being "understood."

Avoid dramatic effects.

Use elegant pulses.

------------------------------------------------------------------------

# Phase 4 --- Synchronization Complete

Type:

    > Studio synchronized.

    > Building workspace...

Pause.

------------------------------------------------------------------------

# Phase 5 --- Gravity

Every physical object begins moving.

Nothing fades.

Everything is pulled toward one invisible point.

Think gravity.

Think magnetic attraction.

The objects become data.

------------------------------------------------------------------------

# Phase 6 --- Workspace Emerges

The dashboard does not fade in.

It grows from the convergence point.

Every widget is born from a real object.

Mapping:

-   Phone → Leads
-   Calendar → Today's Shoots
-   Contract → Payments
-   Album → Deliveries
-   Folder Stack → Projects

The user immediately understands where every piece of information came
from.

------------------------------------------------------------------------

# Visual Language

Background:

    #F7F5F2

Keep the premium ivory aesthetic.

Avoid dark mode.

Avoid neon.

Avoid hacker styling.

Console text should be understated.

------------------------------------------------------------------------

# Motion

References:

-   Apple Keynote
-   Arc Browser
-   Raycast
-   Linear

Motion principles:

-   Smooth easing
-   Subtle pulses
-   Magnetic attraction
-   No spinning
-   No explosions
-   No excessive scaling

Every movement should feel intentional and expensive.

# Emotional Goal

The visitor should think:

> "SnapOps understood my studio before showing me my workspace."

Not:

> "Here comes another dashboard."

This scene should establish SnapOps as an intelligent operating system
for wedding studios rather than just another CRM.
