# SnapOps -- Scene 3: Morning Brief

## Vision

We are **NOT** building another SaaS dashboard.

We are building a cinematic transition where **SnapOps comes alive like
JARVIS**.

The feeling should be: - Calm - Intelligent - Premium - Editorial -
Luxury - Minimal

Imagine opening a MacBook for the first time. Imagine JARVIS waking up.
Imagine Notion + Apple + Linear + Arc Browser.

**NOT** cyberpunk. **NOT** dark mode. **NOT** hacker. **NOT** Matrix.

The website uses a warm ivory background (`#F7F5F2`) and should continue
the visual language from Scene 2.

------------------------------------------------------------------------

# Narrative

Scene 2 ends with every moving part of a wedding studio assembling
together.

As soon as the final object settles:

-   Pause (200ms)
-   Everything becomes still.
-   The screen feels alive.

------------------------------------------------------------------------

# Phase 1 --- AI Wakes Up

Nothing except a blinking cursor.

Small. Monospace. Left aligned. Around 20% from the left and 40%
vertically.

    ▌

Cursor blinks twice.

Then types:

    > Good morning, Bharath.

Typing should feel like an operating system.

Each character appears naturally.

Cursor continues blinking.

Pause.

------------------------------------------------------------------------

# Phase 2 --- Studio Scan

Type:

    > Scanning your studio...

Then reveal:

    ✓ 4 payments found
    ✓ 3 shoots today
    ✓ 2 albums awaiting approval
    ✓ 18 active clients

Elegant, understated diagnostics.

------------------------------------------------------------------------

# Phase 3 --- Workspace

Type:

    > Building today's workspace...

Pause.

Cursor stops.

------------------------------------------------------------------------

# Phase 4 --- Layout Transformation

The terminal remains visible.

It slides left about 25%.

It scales slightly smaller.

It becomes the AI narrator.

The dashboard assembles on the right.

------------------------------------------------------------------------

# Dashboard Assembly

Cards fly into place magnetically.

Order:

1.  Rahul & Sneha
2.  Collect ₹80,000
3.  Album Approval
4.  Expected Collections
5.  Today's Focus
6.  Studio Status

Tiny bounce. Soft easing. No dramatic motion.

------------------------------------------------------------------------

# Visual Style

Cards should feel like premium paper.

Rounded corners. Lots of whitespace. Editorial typography. Soft shadows.
No gradients.

Inspired by Apple, Framer and Linear.
