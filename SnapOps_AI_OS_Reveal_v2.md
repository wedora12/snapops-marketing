# SnapOps Scene 3 — AI Operating System Reveal (v2)

## Vision
Reveal the intelligence behind SnapOps before revealing the workspace.
The user should feel like the operating system has quietly understood the studio.

Mood:
- Calm
- Premium
- Editorial
- Confident
- Minimal

No hacker aesthetic.
No dark mode.
No cyberpunk.
Background remains warm ivory (`#F7F5F2`).

---

# Story Flow

## Scene 2 Ends
The flatlay finishes assembling.
Hold.
200ms of silence.
Everything becomes still.

---

# Phase 1 — AI Awakens
A tiny blinking cursor appears in the **center** of the screen.

```
▌
```

Cursor blinks twice.

Then types:

```
Good morning, Boss.
```

Small monospace font.
Not a headline.
Not bold.
Not dramatic.

Pause.

---

# Phase 2 — Studio Analysis
Type:

```
Analyzing your studio...
```

Then reveal one by one:

```
Payments      ✓
Shoots        ✓
Albums        ✓
Projects      ✓
```

Minimal.
Clean.
Elegant.
No long sentences.
No unnecessary narration.

---

# Phase 3 — Studio Synchronization
Type:

```
Everything is in sync.
```

Pause.

Then:

```
Building today's workspace...
```

---

# Phase 4 — Desk Responds
Each real object reacts when recognized.

- Phone glows softly
- Calendar glows
- Contract glows
- Album glows
- Folder stack glows

The desk feels understood.

---

# Phase 5 — Workspace Reveal
Every object is drawn toward a single invisible point.
The workspace grows from that convergence.

Nothing fades.
Nothing pops.
Everything is constructed.

Mapping:
- Phone → Leads
- Calendar → Today's Shoots
- Contract → Payments
- Album → Deliveries
- Folder Stack → Projects

---

References:

- Aggressive scaling

# Emotional Goal

The visitor should think:

> "This system already understands my studio."

Not:

> "I'm opening another CRM."

The reveal should establish SnapOps as an AI operating system for wedding studios rather than just another CRM.
